# H-Statistic
Calculates the seasonal hysteresis statistic (H), which measures whether actual evapotranspiration lags or leads potential evapotranspiration across the season.

MATLAB code to calculate the seasonal hysteresis statistic H, which compares actual evapotranspiration (AET) at matched potential evapotranspiration (PET) values between the increasing and decreasing limbs of each annual PET cycle. H < 0 means AET is lower early in the season than late, relative to atmospheric demand; H > 0 means the reverse. The method is adapted from Zuecco et al. (2016) and used in Burns et al. (in review), Global prevalence of late-season water use by vegetation.
